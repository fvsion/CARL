# Tiny Todo

A to-do list in one static page: HTML, CSS and plain JavaScript, no build step, no libraries.

    python3 -m http.server 8765      # then open http://127.0.0.1:8765/

## Files

- `index.html`: the page
- `app.js`: the list, the buttons and the counter
- `style.css`: the look

The list lives in memory only: a reload empties it.
